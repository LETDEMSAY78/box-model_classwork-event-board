Box Model Assignment: Events Board

Suggested time: 2 hours. 100 marks.

Build the page shown in target.png from scratch, writing both the HTML and the CSS. The text and pictures you need are in content.txt and the img folder. Match the target at a browser width of 1200px, and meet every measurement below. Use DevTools to measure your own work as you go.

You may not use flexbox, grid, float, position, !important or JavaScript. Use class selectors, and write semantic HTML.

Measurements
Part of the page What it must do
Box sizing Every element uses border box, set once for the whole page.
Header Padding 16px 24px with a 1px bottom border. The site name and nav links sit on one line. Each nav link is a pill: padding 6px 14px, 1px border, radius 999px, margin-right 6px
Hero At least 200px tall with 48 px of padding top and bottom. Background linear-gradient (135deg, #1c2340, #3a1d12). Heading 2.25 rem. Paragraph no wider than 56 characters.
Event Cards Exactly 300 px wide on screen, including 16px of padding and a 1px border. Margin 0 10px 20px. Three cards per row inside the 960px container, then a new row. Cards line up along their tops.
Card Picture The picture area is 150px high and clips its image. The image fills it without distortion. On hover the image zooms slightly and stays inside the rounded corners.
Card title One line only, with an ellipsis when too long.
Card description No taller than 72px, which is three lines at a 24px line height. It scrolls when the text is longer.
Card tags Pills with padding 4px 10px and Margin 0 6px 6px 0. They wrap onto a new line if needed.
Register button A full-width block, at least 44px high with the text centered.
Notices Panel Exactly 200px high including its padding and border. It scrolls vertically.
Schedule table Never narrower than 720px. When the window is narrow, the table scrolls sideways inside its own rounded wrapper, and the page does not.
Narrow window At a browser width of 600px the page has no browser scrollbar.

Colours and type

Page background #0b0d14. Card and panel background #141824. Borders #2a2f42. Main text #E2f3E7. Muted text #a3a9bd. Accent and buttons #EE6220. Tag background #242a40. Body text 16px in the system font. Store the colours as CSS variables and use them everywhere.
